# 《消费计算统一结果微信端回归测试清单》

## 测试准备

- 使用测试会员登录，保证余额不少于 500 元。
- 清理或停用无关消费折扣活动。
- 记录测试前会员余额。

## 场景一：8折活动消费

1. 管理后台创建消费折扣活动：名称“微信端8折测试”，折扣 `0.8`，状态 `active`，有效期包含当天。
2. 进入消费结算页，选择一个洗车服务并记录原价。
3. 检查优惠活动区域只显示系统匹配的最高优先级活动。
4. 检查费用明细：应付金额应等于原价乘以 `0.8`。
5. 点击确认消费，核对确认弹窗金额与页面应付金额一致。
6. 确认支付，核对余额减少值与弹窗金额一致。
7. 检查消费成功页金额与弹窗金额一致。
8. 进入消费记录，核对实付金额、活动名称和折扣率一致。

## 场景二：活动修改为7折

1. 将同一活动折扣修改为 `0.7`。
2. 返回消费页，重新选择同一服务。
3. 检查页面金额自动更新为原价乘以 `0.7`，不得继续显示旧的8折金额。
4. 检查确认弹窗、余额扣减、成功页和消费记录全部为7折金额。

## 场景三：无活动消费

1. 删除或停用测试折扣活动。
2. 返回消费页并选择服务。
3. 检查应付金额恢复为服务原价。
4. 确认支付后，余额扣减、成功页和消费记录均应等于原价。

## 通过标准

以下五处金额必须完全一致：页面试算、确认弹窗、余额实际减少值、消费成功页、消费记录。
